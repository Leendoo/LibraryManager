This is a Java application for managing a small library. The program can add books, register members, borrow and return books, search for books, and show the status of the books. The project is divided into Book, Member, Library, and LibraryManager to make the code easier to understand and organize. Book is a record because information such as ISBN, title, and author does not need to change after the book is created. The program uses arrays to store books and members because this is required in the assignment. If the Collections Framework had been allowed, I could have used something like ArrayList instead of normal arrays, which would make it easier to add more books and members because the list can grow automatically.
